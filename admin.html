خطوات نشر التحديث على GitHub

  1. اضغط «تصدير library-data.json» واحفظ الملف على جهازك.
  2. افتح مستودع GitHub الخاص بالمكتبة.
  3. ارفع الملف إلى المجلد الرئيسي بجوار index.html، واختر استبدال الملف القديم إن طُلب منك ذلك.
  4. اضغط Commit changes وانتظر حتى يتم تحديث الموقع.

استقبال الملفات من جهازك

يمكنك اختيار ملفات PDF مباشرة من الكمبيوتر أو الهاتف أثناء إضافة مادة أو كتاب. بعد ذلك نزّل «حزمة البيانات وملفات PDF»، وفك ضغطها على جهازك، ثم ارفع library-data.json ومجلد files الناتجين إلى GitHub. لا يرفع الموقع الملفات إلى GitHub من تلقاء نفسه لأن الاستضافة الحالية ثابتة ولا تحتوي على خادم لرفع الملفات.
